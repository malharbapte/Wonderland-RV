The hover cursor — 22px

Plain, as chosen, taken down 20%. Hover each pair — top still is bright, bottom still is dark, because a translucent white circle behaves very differently on the two.

Drawn as a real CSS cursor, so the compositor paints it rather than the page: no lag on fast movement, nothing to run on scroll, and no JavaScript. On a touch screen the whole thing is skipped; there is no cursor to draw. The 28px you hovered last time is kept alongside so the step down is easy to judge.

22px — the new one

White at 40%, 22px across. 28 × 0.8 = 22.4, taken to a whole pixel — a cursor is drawn into a bitmap of exactly this size, so a fractional edge would only come out soft.

The size you hovered before, unchanged, for the comparison. Same circle, same 40% white.
