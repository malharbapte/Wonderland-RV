Quote mark — same page, four display widths

Conversion uses the page’s own root font-size, not viewport width — above 2376 the page stops scaling and those two diverge. Each panel loads the real homepage at a different viewport width and measures the mark against the first letter of the quote. dx and dy are the offsets in artboard units. If the mark is locked they read the same in every panel; if it drifts, they differ. Target is dx 29 / dy 106.
