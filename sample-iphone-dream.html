iPhone — accordion without arrows

A1 with the chevrons gone. Something has to say a row opens, so the three differ in what replaces it. Tap them — the animation is the same in all three.

The animationThe height travels on grid-template-rows from 0fr to 1fr rather than on max-height, so it moves the copy's true height — no guessed maximum to overshoot, no clipping if the text wraps differently. 0.38s on an ease-out curve, with the paragraph fading up five pixels behind it, which is what stops the reveal reading as a shutter.
Worth knowingThe tidier CSS-only version of this animates a grid row from 0fr to 1fr. It does not work here — in an auto-height grid the 1fr row has no free space to claim, so it resolves to zero and the row never opens at all. Measuring is exact and goes back to Safari 12.

S1 — The icon carries it

Nothing but the icon changes: closed it is a hairline outline in grey, open it fills orange. Quietest of the three, and the only one where the heading itself never moves or changes colour.
