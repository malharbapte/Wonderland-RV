The 360 icon

Four candidates, drawn in Illustrator on the same 24×24 frame as the existing set, at 0.96 stroke with round caps and joins — so the weight follows the box size exactly as the why- and range- icons do. Only the first is based on a real library icon (Lucide’s rotate-3d, checked against source); the other three are my own. Each is shown large, then at the sizes it would ship at, then inside the Virtual tour CTA it has to live in.
