2 · The right-margin bug — one cause, five symptoms

When the page margins narrowed, the content column went 1373 → 1624, but every inner grid kept column widths that still add up to 1373. So each one stops 251px short of the right margin. Measured:

SectionRight edgeShould beShort by

Fix: scale each grid’s columns by 1624 / 1373 = 1.1828, which keeps the internal proportions and lands every right edge on 2000.

3 · Brand logos — re-sliced

The old cut used a 26px threshold. Gaps inside a wordmark run 1–25px and gaps between logos start at 33px, so 26 sat on the boundary and cut some marks mid-word. Re-cut at 30px: 21 logos, 7 per row, each verified to have blank edge columns. Hover to check the colour-up.
