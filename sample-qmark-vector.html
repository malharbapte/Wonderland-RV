Quote mark: text glyph vs vector

Placement rule in every pair below: the mark’s bottom-right corner meets the first letter’s top-left corner, so the two touch on the diagonal and the mark sits clear above the line rather than beside it. Same mark, same size, same colour on both sides — the only difference is what the browser is being asked to place: a character in a font, or a shape.

3 · What happens when the brand font isn’t there yet

The fonts load with font-display: swap, so for the first moments of every cold load the mark is drawn in a fallback face — a different shape, sitting in a different place, then it jumps when Aviano arrives. Below, the mark is forced to a fallback to hold that moment still. The vector never has this state.
